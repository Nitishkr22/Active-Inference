  Key findings:

  1. The Pareto cliff is between CL1 and CL2 (83% → 47%), not between CL3/CL4 as
  the training metrics suggested. Halving the GRU from 256→128 is survivable;
  halving again to 64 is not.
  2. CL1 (3.9×) is the viable compression point but still 13% below V5f (96%),
  partly from training variance (CL0 retrained gets 88% — the architecture alone
  explains an 8% floor gap).
  3. The collision problem: CL1 shows 8-12% collision rate — the compressed
  model's collision head underestimates obstacle risk, causing the EFE planner
  to take riskier paths.
  4. ms/step is flat (~1.8ms) across all levels — the GRU dominates inference
  time and all variants fall in the same range.

  The gap between V5f (96%) and CL1 (83%) is likely recoverable via knowledge 
  distillation — that's the natural next experiment. Training from scratch loses
  information that V5f has about navigating this environment; distilling from
  V5f as teacher would transfer that knowledge to the smaller CL1/CL2
  architectures.

  Proposed next steps for ICRA:
  1. Train CL1-KD (knowledge distillation from V5f → CL1 architecture) — expect
  90-95% success
  2. Train CL2-KD — if KD bridges the gap, CL2 might reach 70-80%, making 15×
  compression practical
  3. Run the quantization study (FP16/INT8) on the best CL1 model
  4. Run noise sweep on V5f, CL1, CL1-KD to show robustness vs compression
  tradeoff

  The ICRA contribution becomes much stronger: "Without distillation: 3.9× 
  compression costs 13% accuracy. With knowledge distillation: 15× compression 
  costs <10% accuracy." That's a publishable result.

  Here's what was built:

  train_kd.py — complete, standalone KD training script that:
  - Loads V5f as a frozen teacher (96% nav, 1.68M params)
  - Runs teacher's forward_filter in no_grad on each batch
  - Adds kd_belief_loss = T² × KL(student || teacher_soft) for row/col/heading
  distributions
  - Temperature T=2 (default) softens teacher's peaked beliefs for richer
  gradient signal
  - KD warmup: weight ramps 0→1 over 5 epochs so hard labels establish
  localization first
  - Optional kd_context_loss (off by default, enable with --w_kd_context 0.1)
  - Saves checkpoints in same format as train_compressed.py →
