  Diagnosis — KD degraded both models for the same reason:

  The w_kd_belief=2.0 KD loss dominated training. To minimize KL(student || 
  teacher_soft), the student learned to produce extremely peaked belief
  distributions matching the teacher's. Side effects:
  1. Context collapse: context std dropped from ~0.76 → 0.14. The discrete
  belief factors absorbed all localization, leaving context with nothing to
  encode. The EFE planner's transition model relies on context for rollout
  predictions — with a near-zero context it plans blind.
  2. best_model.pt saved by total loss (hard + KD), not by task performance.
  Early epochs with low KD warmup had lower total loss, so the saved checkpoint
  isn't the best navigator.

  Two bugs in the current approach need fixing:

  Fix 1 — Save criterion: Save best_model.pt based on hard_val_loss only (not
  KD-inflated total). Add this to train_kd.py.

  Fix 2 — Balance KD: Lower belief weight + enable context alignment:
  - w_kd_belief=0.5 (was 2.0): KD as regularizer, not dominant
  - w_kd_context=0.2: forces context to carry meaningful info, prevents collapse
  - kd_temp=3.0 (was 2.0): softer targets → less over-sharpening
  - kd_warmup=10 (was 5): longer ramp for model to establish dynamics first
